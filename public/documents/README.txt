Place the school's real PDFs in this folder.

The eleven files that ship with the template are PLACEHOLDERS generated by
  npm run docs:samples
so that no download link on /resources is broken. Each one says so on the page.

To publish a real document:
  1. save it here with the same file name (e.g. fee-structure.pdf), or a new name
  2. if it is new, add a matching row in content/resources.json
  3. commit + push — Vercel deploys it

Delete this note, and the sample generator, once the real files are in place.
